## 复现

```powershell
.\gradlew.bat build
.\gradlew.bat build '-PpackModsDir=../mods'
.\gradlew.bat runGameTestServer '-PpackModsDir=../mods' '-PintegrationModsDir=libs/integration'
.\gradlew.bat runClient '-PpackModsDir=../mods' '-PintegrationModsDir=libs/integration' -PclientSmokeTest
```

`libs/integration` 是本机忽略的开发依赖目录，存放无用之物 2.4.6.6、AE2 19.2.19、GuideME 21.1.22、Glodium、KubeJS 2101.7.2-build.381、Rhino 2101.2.8-build.91、Architectury 13.0.12；不重复放默认开发依赖。测试脚本源在 `tools/integration/kubejs/`。GameTest 和客户端检查都要求本次运行的新日志标志；GameTest 还检查实际 KubeJS 查询标志，避免脚本异常被吞掉后误报成功。
