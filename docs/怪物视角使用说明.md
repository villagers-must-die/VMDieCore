# 怪物视角 · 永夜档案

对应 `26.11.13.1.策划.md` 的「怪物视角体系」。并入 VMDieCore 后使用 Minecraft 1.21.1 / NeoForge 21.1.266 及以上 / Java 21，客户端和服务端均需安装同一个 JAR。

1.0.2 的构建与回归环境已对齐本整合包的 NeoForge 21.1.266。它修复了「无用之物」2.4.6.6 每 tick 为普通玩家清除燃烧时长的兼容问题；仅在真正解除该模组拥有的免伤状态时保留灭火清理，未修改原模组 JAR。

## 开始使用

首次进入世界自动打开作战身份界面。以后按 **O**，或输入 `/monster` 打开；按键可以在控制设置的「怪物视角」分类修改。点击顶部身份卡，右侧切换「生存特性 / 种族科技」，连续两次点击「确认身份」完成登记。方向键选择种族，Tab 切换页签，Enter 确认。右侧 ↑ / ↓ 按钮翻阅正文，也可滚动鼠标或拖动滚动条；Page Up / Page Down 翻页，Home / End 到首尾。

1.0.1 版本采用搜打撤的行前整备风格：煤黑与军绿面板、沙色纸质化身档案、警戒橙身份卡、自定义切角按钮和实时 3D 模型。常规正文从旧版的 9 号提高到 16 号，标题最大 30 号；小窗口使用 15 号正文和滚动阅读。弱点以警戒色强调，底栏保留行动提醒，没有使用原版按钮或背包面板贴图。五种族均可选；**血族始终使用玩家自身模型和皮肤**。种族保存在玩家数据中，死亡、重进及跨维度后保留，并同步给其他客户端。

### 傀儡装配联动

使用现有的 Modular Golems 3.1.44。肉、骨部件既是对应原生材料的输入，也可以与已有金属/人形/犬型傀儡部件无序合成，将其转换成血肉/魂骨材质，再通过原生装配流程组装。支持混合材质；只要包含相应材质的部件，就具备对应能力。材料、修理材料、属性与材质贴图均已接入。

僵尸或血族受到致命伤时，会消耗自己拥有、仍存活、已加载且落点可容纳玩家的一只肉傀儡，回满生命并移到该处，保留物品。跨维度也可生效，不会强制加载未知区块。虚弱金苹果处死不触发替身。魂骨傀儡受到致命伤时回复全部生命，随后进入默认 5 分钟冷却。冷却保存在傀儡数据中。

### Ender IO 联动

当前整合包未安装 Ender IO。已核对其 1.21.1 分支的实际物品 ID，加入条件加载配方：

- 无限珍珠 + 铁块 + 红石块 + 黑曜石 → `enderio:travel_anchor`
- 无限珍珠 + 铁块 + 红石块 + 烈焰棒 → `enderio:staff_of_travelling`

装入 Ender IO 后自动启用。未安装时跳过，不注册不存在的物品，不影响整合包加载。没有为该版本不存在的传输器虚构物品 ID。

## 管理与配置

管理员指令（需要权限 2）：

```text
/monster race <玩家> zombie
/monster race <玩家> skeleton
/monster race <玩家> enderman
/monster race <玩家> arthropod
/monster race <玩家> vampire
/monster race <玩家> reset
```

每个存档的 `serverconfig/monsterperspective-server.toml`：

```toml
allowReselection = true
raceChangeCooldown = 60
boneReviveCooldown = 300
```

允许界面重选、重选冷却秒数、骨傀儡复活冷却秒数。可以在整合包的 `defaultconfigs` 提供新存档默认值。更换身体前检查空间，避免末影人或蜘蛛在狭小处卡进方块。

`/monster status` 可查看自己在服务端的种族、游戏模式、日照判定、头部装备、燃烧剩余时长及飞行权限，方便检查环境或其他模组的影响。日照以眼部位置判定，三族使用原版火焰伤害节奏；创造模式保留伤害免疫并同步火焰外观，旁观模式不触发。僵尸下沉、骷髅上浮不会作用于创造模式、拥有飞行权限的玩家或骑乘状态。牛奶产骨仍按原策划要求：开始喝牛奶时满血才获得骨头。

## 构建与资源

本模块已并入 `VMDieCore/`，不再独立加载。源码、Gradle Wrapper、全部资源与图标生成源都已提供。

```powershell
.\gradlew.bat build
.\gradlew.bat runGameTestServer
python tools\generate_resources.py
```

构建生成 `build/libs/vmdiecore-0.2.0.jar`。安装时用核心 JAR 替换旧独立怪物视角 JAR，不能同时安装。重新生成图标需 Python + Pillow。`tools/generate_resources.py` 是可编辑整数像素绘图源，`tools/pixels.generated.json` 保存逐像素导出。游戏物品图标均为原生 16×16 RGBA，无缩图和抗锯齿；`docs/items-preview.png` 同时提供原尺寸和最近邻放大预览。

自动化测试源码位于 `src/gameTest/java/org/dishanhai/vmdiecore/monster/test/MonsterGameTests.java`，测试世界与客户端均使用独立 `run-*` 目录。验证范围和结果见本仓库的 `docs/移植验证记录.md`。

实现参考：NeoForge 1.21.1 官方事件/网络文档；[Woodwalkers v5](https://github.com/ToCraft/woodwalkers-mod/tree/v5) 的玩家化身、视点及模型状态同步思路。本模块不需要安装化身模组。傀儡纹理由本整合包 Modular Golems 中的铁材质纹理派生，版权及 LGPL-2.1 归原模组作者；本项目保留可重建的转换源。
