# feat: 为 VMDieCore 添加怪物视角体系（种族科技未完成）

为 VMDieCore 添加五族身体、模型、身份 UI、数据同步和种族科技基础功能，版本提升至 0.2.0。

**建议以 Draft PR 提交。种族科技属于未完成部分：当前配方种族限制只覆盖原版合成流程，其他模组的工作台、自动合成或机器流程可以绕过，科技解锁尚未形成完整约束。**

## 本次改动

- 接入僵尸、骷髅、末影人、节肢生物和血族的身体能力、碰撞箱、模型、第一人称及种族同步；血族保持玩家模型和自身皮肤。
- 新增搜打撤风格的身份选择 UI，采用大字号、军绿/沙色面板，提供 O 键和 `/monster` 入口。
- 添加克隆、灵魂、传送、纺织的基础物品、配方和效果，以及血族共享科技判定；跨模组配方权限尚未完成。
- 接入 Modular Golems 材料和 Curios 槽位；处理燃烧兼容、飞行豁免和满血开始喝牛奶才产骨的规则。
- 新增服务端 KubeJS 种族/科技查询绑定，保留现有 `VMDieStacking` 绑定。

## 未完成：种族科技的跨模组限制

目前权限检查位于原版合成菜单更新流程，能够限制原版背包合成、原版工作台及其批量合成，以及在这些菜单内进行的傀儡部件转换。检查并未覆盖配方在其他模组中的执行路径，其他模组可以绕过原版菜单检查取得受限科技产物。

`VMDieTechnology.hasTech` 仅提供科技资格查询，不会自动拦截其他模组的合成，也不能视为跨模组科技权限已实现。

## 配置与依赖

- 由 `vmdiecore` 统一管理模组生命周期，傀儡材料和 Curios 玩家槽位配置位于 `data/vmdiecore/`。
- 开发依赖对齐 Java 21、Minecraft 1.21.1、NeoForge 21.1.266 及整合包现有前置；第三方模组不打入核心 JAR。
